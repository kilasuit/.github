# kilasuit standards

This repository provides the base standardised templates across all repos across `kilasuit` repos.

GitHub automatically applies the files in `.github/` to every repository in the
org that does not define its own version helping standardise how "Interactions"
with these repos looks like.

This is all a work in progress and was adapted from the [Powershell.Org implementation](https://github.com/powershellorg/.github)
as well as the individual repos that had already started with some implementations.
